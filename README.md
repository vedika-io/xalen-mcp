# Xalen MCP server (legacy snapshot)

This repository is retained as historical source for an early Xalen MCP server. It is not the canonical source for current Xalen MCP releases, tool counts, capabilities, or installation guidance.

The maintained server lives in Xalen's private product monorepo. Current installation and API guidance belongs at [xalen.io/docs](https://xalen.io/docs).

## Product boundary

- **Xalen** is the parent company's AI platform.
- **Vedika** is Xalen Technology's astrology intelligence product and has its own API and MCP namespace.
- **XALEN Ephemeris** is a shared calculation engine. It is not this MCP server.

For Vedika integrations, use the official tools listed on the [Vedika GitHub profile](https://github.com/vedika-io), including `@vedika-io/mcp-server`.

## Status

Historical and unsupported. The earlier tool list and setup examples were removed because they no longer establish the behavior of current releases. Issues and pull requests are not accepted here.
